SSH setup guide

      
Most VMs need none of this. Tart Oven runs Send command and Get info through the Tart guest agent — no SSH, no key, no credentials — and the official ghcr.io/cirruslabs/macos-*-base images ship the agent preinstalled. The VM row shows agent when that path is in use.

      
Follow the steps below only for a guest without the agent (for example a vanilla-* image), where Tart Oven falls back to SSH. To add the agent to such an image instead, run brew install openai/tools/tart-guest-agent inside the guest once, before cloning it. Run the commands below on the Mac mini — the key stays on the mini.


      
1 · Generate a key (once)

      


      
2 · Send the public key to a VM

      

        
        pick a running VM, then run:
      

      

      
You'll enter the VM's password once. The VM must have Remote Login on (System Settings → General → Sharing). This command fixes the ~/.ssh permissions that often block ssh-copy-id, and skips host-key fingerprint prompts / known_hosts entries (so reused VM IPs never cause conflicts — the same way Tart Oven connects).


      
3 · Point Tart Oven at the key

      
Set SSH identity file in Configuration to ~/.ssh/tart-oven, then click Save configuration. Test it with Get info on a running VM.


      
Tip · Do it once for the whole fleet

      
Add the public key to your TEMPLATE VM's ~/.ssh/authorized_keys before cloning — every clone inherits it, so you never repeat steps 1–2.
